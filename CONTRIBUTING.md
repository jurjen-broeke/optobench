# Contributing

Thanks for helping. Read [AGENTS.md](AGENTS.md) first: its non-negotiables apply to human
and agent contributors alike, especially the clean-room and licence rules.

- One milestone task per pull request; reference the task in `docs/milestones/`.
- Every new reference value in a test cites its source.
- New names (crates, commands, file kinds, extensions) pass `cargo xtask naming`.
- Adapted code or bundled data adds a row to `ATTRIBUTION.md` (and `assets/manifest.toml`).
